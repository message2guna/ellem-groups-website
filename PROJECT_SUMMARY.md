## 🎨 Customization Guide

### Essential Updates

**1. Update Contact Information** (5 minutes)
- File: `/app/contact/page.tsx`
- Update: Email, phone, addresses, business hours

**2. Update Footer & Social Links** (3 minutes)
- File: `/components/Footer.tsx`
- Update: Social media links, company info

**3. Customize Company Descriptions** (15 minutes)
- `/app/foundry/page.tsx` - Foundry details
- `/app/engineering/page.tsx` - Engineering details
- `/app/fluid-control/page.tsx` - Fluid Control details

**4. Customize Brand Colors** (Optional)
- File: `/styles/globals.css`
- Update CSS variables: `--primary`, `--secondary`, `--accent`

**5. Add Company Images** (30-60 minutes)
- Create folders: `public/foundry/`, `public/engineering/`, `public/fluid-control/`
- Add images: foundry-1.jpg, engineering-1.jpg, etc.
- Update image paths in page files

### File Structure to Customize

