🎨 EDITING GUIDE:

TO UPDATE CONTACT INFO:
  → Open: app/contact/page.tsx
  → Find: "Contact Information" section
  → Update: Phone, email, addresses, hours

TO UPDATE COMPANY INFO:
  → Open: app/foundry/page.tsx (or engineering/page.tsx or fluid-control/page.tsx)
  → Find: "About" section
  → Update: Description, services, capabilities

TO ADD IMAGES:
  → Create folders in public/: foundry/, engineering/, fluid-control/
  → Add images: foundry-1.jpg, foundry-2.jpg, etc.
  → Update paths in page files

TO CHANGE COLORS:
  → Open: styles/globals.css
  → Find: :root { ... } section
  → Update: --primary, --secondary, --accent colors

TO UPDATE FOOTER:
  → Open: components/Footer.tsx
  → Update: Email, phone, social links, company info
